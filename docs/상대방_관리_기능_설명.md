# 상대방 관리 기능 명세서

## 📌 기능 개요

상대방 관리 기능은 사용자가 분석 대상인 상대방의 정보를 저장하고 관리할 수 있는 핵심 기능입니다. 저장된 상대방 정보는 대화 분석, 답장 생성, 궁합 보기 등 다양한 기능에서 활용되어 더 정확하고 개인화된 분석 결과를 제공합니다.

**비즈니스 가치:**
- 사용자가 여러 상대방을 관리하며 지속적으로 앱을 사용하도록 유도
- 상대방 정보 입력을 통해 분석 정확도 향상 및 사용자 만족도 증가
- 현재 상대 설정을 통한 직관적인 기능 접근성 제공

---

## 🏠 상대방 관리 페이지

### 접근 경로
- 홈 화면의 "현재 상대" 카드 클릭
- 기타 기능에서 상대방 정보 저장 시 자동 이동

### 화면 구성

#### 상단 영역
- **제목**: "상대 관리"
- **설명 문구**: "상대 정보를 저장하고 분석에 반영해요"
- **뒤로가기 버튼**: 홈 화면으로 복귀

#### 메인 콘텐츠 영역

**상대방이 없는 경우 (빈 상태):**
- 안내 아이콘 및 메시지 표시
- "저장된 상대가 없어요" 안내
- "상대 정보를 추가하면 대화 분석/추천이 더 정확해져요" 설명
- "상대 추가하기" 버튼 (강조된 스타일)

**상대방이 있는 경우:**
- 저장된 상대방 카드들이 세로로 리스트 형태로 표시
- 각 카드에는 상대방의 기본 정보와 관리 버튼 표시
- 하단에 "새로운 상대방 추가하기" 버튼 표시

**상대방이 3명인 경우:**
- 하단 버튼이 비활성화되고 "최대 3명까지만 추가할 수 있어요" 메시지 표시

## 📝 상대방 카드 정보

### 카드 표시 정보

#### 1. 기본 정보
- **상대방 이름** (가장 큰 글씨로 강조)
- **"현재 상대" 배지** (현재 상대로 설정된 경우에만 표시)
- **관계 단계 태그** (썸, 연애, 소개팅, 친구, 기타 중 선택된 항목)

#### 2. 추가 정보 배지
- **MBTI 배지**: MBTI가 입력된 경우 "MBTI: {유형}" 형태로 표시
- **사주 정보 배지**: 
  - 사주 입력됨: "사주 입력됨" 표시
  - 사주 미입력: "사주 미입력" 표시

#### 3. 메모
- 상대방에 대한 메모가 있는 경우 표시
- 긴 메모는 2줄까지만 표시하고 나머지는 생략

#### 4. 액션 버튼
- **수정 버튼**: 상대방 정보 수정 페이지로 이동
- **삭제 버튼**: 삭제 확인 후 상대방 정보 삭제

### 카드 동작
- **카드 전체 클릭**: 해당 상대방을 현재 상대로 자동 설정
- **수정 버튼 클릭**: 상대방 정보 수정 페이지로 이동
- **삭제 버튼 클릭**: 삭제 확인 후 상대방 정보 삭제

## ➕ 상대방 추가 기능

### 접근 경로
- 상대방 관리 페이지의 "상대 추가하기" 또는 "새로운 상대방 추가하기" 버튼 클릭
- 궁합 보기 등 다른 기능에서 상대방 정보 저장 시 자동 이동

### 입력 항목

#### 1. 이름 (필수)
- **입력 방식**: 텍스트 입력 필드
- **안내 문구**: "상대방 이름을 입력하세요"
- **제한**: 최대 20자
- **검증**: 이름을 입력하지 않으면 "이름을 입력해주세요" 오류 메시지 표시

#### 2. 관계 단계 (선택)
- **선택 옵션**: 썸, 연애, 소개팅, 친구, 기타
- **표시 방식**: 버튼 형태로 나열, 선택 시 강조 표시
- **선택 규칙**: 하나만 선택 가능, 선택 해제 가능

#### 3. MBTI (선택)
- **입력 방식**: MBTI 선택 도구 사용
- **형식**: 4자리 MBTI 코드 (예: ENFP, ISTJ)
- **검증**: 올바른 MBTI 형식이 아니면 "올바른 MBTI 형식이 아닙니다" 오류 메시지 표시
- **저장**: 대문자로 자동 변환하여 저장

#### 4. 사주 정보 (선택)

**달력 종류:**
- 양력 또는 음력 중 선택

**생년월일:**
- 연도: 드롭다운 선택 (현재 연도부터 100년 전까지)
- 월: 드롭다운 선택 (1월~12월)
- 일: 드롭다운 선택 (1일~31일)
- **입력 규칙**: 생년월일을 입력하기 시작하면 연도, 월, 일 모두 입력해야 함
- **검증 범위**: 
  - 연도: 1900년부터 현재 연도까지
  - 월: 1~12
  - 일: 1~31

**출생 시간 (선택):**
- "출생 시간도 입력할게요" 체크박스
- 체크 시 시간과 분 입력 필드 표시
  - 시간: 드롭다운 선택 (0시~23시)
  - 분: 드롭다운 선택 (0분~59분)
- 체크 해제 시 시간/분 입력 필드 숨김

#### 5. 메모 (선택)
- **입력 방식**: 여러 줄 텍스트 입력 영역
- **안내 문구**: "기억하고 싶은 내용을 입력하세요"
- **제한**: 최대 200자
- **글자 수 표시**: 입력 영역 하단에 "현재 글자 수/200자" 표시

### 제출 및 취소
- **취소 버튼**: 입력 내용을 취소하고 이전 페이지로 돌아가기
- **추가하기 버튼**: 모든 입력 항목 검증 후 상대방 추가

### 추가 완료 후 동작
- 새로 추가된 상대방이 **자동으로 현재 상대로 설정**됨
- 상대방 관리 페이지로 이동
- 다른 기능에서 상대방 추가를 시작한 경우, 해당 기능 페이지로 복귀

## ✏️ 상대방 수정 기능

### 접근 경로
- 상대방 관리 페이지에서 상대방 카드의 "수정" 버튼 클릭

### 수정 화면
- **기본 구조**: 상대방 추가 화면과 동일한 입력 폼
- **차이점**:
  - 기존 상대방 정보가 모든 입력 필드에 미리 채워져 있음
  - 제출 버튼 텍스트가 "수정 완료"로 표시됨

### 수정 완료 후 동작
- 수정된 정보가 저장됨
- 상대방 관리 페이지로 자동 이동

---

## 🗑️ 상대방 삭제 기능

### 삭제 절차
1. 상대방 관리 페이지에서 상대방 카드의 "삭제" 버튼 클릭
2. 확인 메시지 표시: "정말 {이름}님의 정보를 삭제하시겠어요?"
3. 확인 시 상대방 정보 삭제
4. 삭제 후 상대방 목록에서 제거됨

### 특수 처리
- **현재 상대로 설정된 상대방을 삭제하는 경우**: 현재 상대 설정도 자동으로 초기화됨

## ⭐ 현재 상대로 설정

### 설정 방법
- **상대방 관리 페이지**: 상대방 카드 클릭
- **자동 설정**: 새 상대방 추가 시 자동으로 현재 상대로 설정됨

### 현재 상대의 활용
- **대화 분석**: 현재 상대방의 MBTI 정보가 분석 결과에 반영되어 더 정확한 분석 제공
- **답장 생성**: 현재 상대방의 정보를 바탕으로 맞춤형 답장 생성
- **궁합 보기**: 현재 상대방과의 궁합을 기본으로 표시
- **홈 화면**: "현재 상대" 카드에 현재 상대방 정보 표시

### 표시 방법
- **상대방 관리 페이지**: 현재 상대로 설정된 카드에 "현재 상대" 배지 표시
- **홈 화면**: "현재 상대" 카드에 상대방 이름, 관계 단계, MBTI 정보 표시

---

## 🔒 제한 사항

### 최대 상대방 수
- **제한**: 최대 3명까지만 추가 가능
- **제한 적용 시점**:
  - 상대방 추가 시도 시 검증
  - 상대방이 3명이면 추가 버튼 비활성화

### 입력 제한
- **이름**: 최대 20자
- **메모**: 최대 200자
- **MBTI**: 4자리 형식만 허용 (E/I, S/N, T/F, J/P 조합)

## 🎯 사용 시나리오

### 시나리오 1: 첫 상대방 추가
```
1. 홈 화면에서 "현재 상대" 카드 클릭
   ↓
2. "상대 추가하기" 버튼 클릭
   ↓
3. 이름 입력 (필수)
   ↓
4. 관계 단계, MBTI, 사주 정보, 메모 입력 (선택)
   ↓
5. "추가하기" 버튼 클릭
   ↓
6. 상대방 관리 페이지로 이동
   ↓
7. 새로 추가된 상대방이 "현재 상대"로 자동 설정됨
```

### 시나리오 2: 여러 상대방 관리
```
1. 상대방 관리 페이지에서 여러 상대방 추가 (최대 3명)
   ↓
2. 각 상대방 카드를 클릭하여 현재 상대로 전환
   ↓
3. 대화 분석, 답장 생성 등에서 현재 상대방 정보 활용
   ↓
4. 필요 시 상대방 정보 수정 또는 삭제
```

### 시나리오 3: 궁합 보기에서 상대방 추가
```
1. 궁합 보기 페이지에서 상대방 정보 입력
   ↓
2. "상대 정보 저장하기" 옵션 선택
   ↓
3. 상대방 추가 페이지로 이동
   ↓
4. 상대방 정보 입력 및 저장
   ↓
5. 궁합 페이지로 돌아가서 저장된 상대방과 궁합 확인
```

## 💡 주요 특징

### 1. 간편한 정보 입력
- **필수 정보**: 이름만 입력하면 상대방 추가 가능
- **선택 정보**: 관계 단계, MBTI, 사주 정보, 메모는 선택사항
- **정보 활용**: 선택 정보를 입력할수록 대화 분석과 답장 생성의 정확도가 향상됨

### 2. 유연한 관계 관리
- 여러 상대방을 저장하고 쉽게 전환 가능
- 각 상대방별로 다른 정보 저장 가능
- 현재 상대 설정을 통한 직관적인 기능 접근

### 3. 데이터 동기화
- 로그인된 사용자는 여러 기기에서 동일한 상대방 정보 사용 가능
- 오프라인에서도 기본 기능 작동
- 데이터는 자동으로 동기화됨

### 4. 직관적인 사용성
- 카드 형태로 정보를 한눈에 파악 가능
- 현재 상대방이 명확하게 표시됨
- 간단한 클릭으로 현재 상대 전환 가능

## 📊 비즈니스 가치

### 사용자 경험 향상
- 상대방 정보를 저장함으로써 매번 정보를 입력할 필요 없음
- 여러 상대방을 관리하며 다양한 관계 분석 가능
- 현재 상대 설정을 통한 빠른 기능 접근

### 분석 정확도 향상
- 상대방의 MBTI나 사주 정보가 있으면 더 정확한 분석 제공
- 저장된 정보를 바탕으로 개인화된 답장 생성
- 궁합 분석의 정확도 향상

### 사용자 참여도 증가
- 상대방 정보 입력을 통한 앱 사용 시간 증가
- 여러 상대방 관리로 지속적인 앱 사용 유도
- 정보 입력에 따른 기능 활용도 증가

## 📝 참고사항

- **로그인 권장**: 여러 기기에서 동일한 상대방 정보를 사용하려면 로그인이 필요합니다
- **오프라인 지원**: 로그인하지 않아도 기본 기능은 사용 가능합니다
- **정보 활용**: 상대방의 MBTI나 사주 정보가 있으면 대화 분석과 답장 생성의 정확도가 향상됩니다
- **현재 상대 설정**: 대화 분석이나 답장 생성 시 현재 상대로 설정된 상대방의 정보가 자동으로 사용됩니다
