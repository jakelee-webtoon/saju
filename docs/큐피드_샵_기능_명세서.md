# 큐피드 샵 기능 명세서

## 📌 기능 개요

큐피드 샵은 사용자가 큐피드 화살을 구매할 수 있는 결제 기능입니다. 큐피드 화살은 앱 내 특정 기능(답장 생성 등)을 사용할 때 소모되는 가상 화폐입니다. 사용자는 다양한 패키지를 선택하여 화살을 충전하고, 결제 시스템을 통해 실제 금액으로 구매할 수 있습니다.

**비즈니스 가치:**
- 앱의 주요 수익원
- 사용자가 필요한 만큼 화살을 구매하여 기능을 계속 사용할 수 있도록 지원
- 다양한 패키지 옵션 제공으로 사용자 선택권 확대
- 결제 시스템 연동을 통한 안전하고 편리한 구매 경험 제공

---

## 🏠 화면 구성

### 접근 경로
- 마이페이지(MY 탭)의 "충전" 버튼 클릭
- 직접 접근: `/shop` 경로로 이동
- 화살 잔액이 부족할 때 자동으로 샵 페이지로 이동

### 상단 헤더
- **뒤로가기 버튼**: 마이페이지로 복귀
- **제목**: "💘 큐피드 샵"
- **설명**: "망설이는 순간, 화살 하나로 결정하세요"

## 💰 화살 잔액 표시

### 잔액 뱃지
- **위치**: 헤더 바로 아래
- **표시 내용**:
  - "내 큐피드 화살" 라벨
  - 화살 이모지 (🔥)
  - 현재 잔액 (큰 숫자, 굵게)

### 잔액 상태별 디자인
- **잔액이 0개인 경우**:
  - 배경: 노란색 계열
  - 테두리: 노란색
  - 텍스트: 노란색
  - 경고 메시지: "⚠️ 화살이 없어요! 아래에서 충전해보세요"
- **잔액이 있는 경우**:
  - 배경: 흰색
  - 테두리: 보라색
  - 텍스트: 보라색

## 📦 화살 패키지

### 패키지 종류 (4개)

#### 1. Starter 패키지
- **화살 개수**: 5개
- **가격**: 1,000원
- **설명**: "오늘 고민 몇 개 해결하기 딱 좋아요"
- **특징**: 기본 패키지, 가장 저렴한 가격

#### 2. Best 패키지 (추천)
- **화살 개수**: 15개
- **가격**: 2,500원
- **설명**: "이번 주 연애 고민은 충분해요"
- **특징**: 
  - "⭐ 가장 추천" 배지 표시
  - 보라색-핑크 그라데이션 배경
  - 두꺼운 테두리
  - 강조된 디자인

#### 3. Heavy 패키지
- **화살 개수**: 40개
- **가격**: 5,900원
- **설명**: "마음 가는 대로 써도 부족하지 않아요"
- **특징**: 가장 많은 화살 제공, 대량 구매용

#### 4. Limited 패키지 (한정)
- **화살 개수**: 20개 + 보너스 5개 (총 25개)
- **가격**: 2,900원
- **설명**: "오늘만 추가 지급!"
- **특징**:
  - "⏰ 오늘만" 배지 표시
  - 보너스 화살 5개 추가 지급
  - "실제 25개 지급!" 안내 문구

### 패키지 카드 디자인

#### 기본 디자인
- **배경**: 흰색
- **테두리**: 회색
- **그림자**: 약한 그림자

#### 추천 패키지 디자인
- **배경**: 보라색-핑크 그라데이션
- **테두리**: 보라색, 두꺼운 테두리
- **그림자**: 강한 그림자
- **배지**: 상단에 "⭐ 가장 추천" 배지

#### 한정 패키지 디자인
- **배경**: 흰색
- **테두리**: 회색
- **배지**: 상단에 "⏰ 오늘만" 배지 (주황색-오렌지 그라데이션)

### 패키지 카드 내용

#### 제목
- **형식**: "💘 큐피드 화살 {개수}개"
- **보너스 표시**: 보너스가 있으면 "+{보너스 개수}개" (분홍색 텍스트)

#### 설명
- 각 패키지의 사용 시나리오 설명

#### 가격 및 버튼 영역
- **가격 표시**: 큰 숫자로 표시 (예: "2,500원")
- **보너스 안내**: 보너스가 있으면 "실제 {총 개수}개 지급!" 표시
- **충전하기 버튼**:
  - 추천 패키지: 보라색-핑크 그라데이션 배경, 흰색 텍스트
  - 일반 패키지: 검은색 배경, 흰색 텍스트
  - 클릭 시 결제 프로세스 시작

## 💳 결제 프로세스

### 결제 전 확인
- **로그인 확인**: 로그인되지 않은 경우 로그인 페이지로 이동
- **결제 시스템 준비**: PortOne SDK 초기화 확인

### 결제 요청
- **결제 정보 저장**: 결제 정보를 임시 저장
- **결제 방식**: 카카오페이 (기본)
- **결제 정보**:
  - 상품명: "큐피드 화살 {패키지명}"
  - 결제 금액: 패키지 가격
  - 결제 방법: 카드
  - 구매자 이름: 사용자 닉네임

### 결제 검증
- 결제 완료 후 서버에서 결제 검증
- 결제 정보 확인 (금액, 상품명 등)

### 화살 충전
- **충전 개수**: 패키지 화살 개수 + 보너스 화살 개수
- **충전 방식**: Firebase와 localStorage 동시 업데이트
- **잔액 업데이트**: 실시간으로 잔액 표시 업데이트

### 결제 내역 저장
- 결제 완료 시 결제 내역을 Firebase에 저장
- 저장 정보:
  - 패키지 ID, 패키지명
  - 결제 금액
  - 충전된 화살 개수
  - 결제 방법
  - 결제 고유 ID
  - 결제 상태

### 통계 업데이트
- 화살 구매 통계 업데이트
- 상점 사용 통계 업데이트

### 성공 메시지
- **토스트 메시지**: "💘 화살 {개수}개가 충전됐어요!"
- **표시 시간**: 2.5초 후 자동 사라짐

### 결제 실패/취소
- **취소 시**: "결제가 취소되었어요" 메시지
- **실패 시**: 에러 메시지 표시
- **검증 실패 시**: "결제 검증에 실패했어요 😢" 메시지

## 🔄 화살 잔액 관리

### 잔액 저장 방식
- **로그인 사용자**: Firebase에 저장 (여러 기기에서 동기화)
- **비로그인 사용자**: localStorage에 저장 (해당 기기에서만 사용)
- **동기화**: 로그인 시 Firebase 잔액으로 자동 동기화

### 잔액 표시 위치
- **큐피드 샵**: 상단 잔액 뱃지
- **마이페이지**: 큐피드 화살 카드
- **답장 생성기**: 헤더에 잔액 표시
- **기타 기능**: 화살 사용 시 잔액 확인

### 잔액 업데이트
- **실시간 업데이트**: 화살 충전 또는 사용 시 즉시 반영
- **자동 동기화**: 로그인 사용자는 여러 기기에서 자동 동기화

### 가격 체계
- **Starter**: 1,000원 (5개) - 개당 200원

- **Heavy**: 5,900원 (40개) - 개당 약 148원 (대량 구매 할인)
- **Limited**: 2,900원 (25개) - 개당 약 116원 (보너스 포함 시 가장 저렴)

### 가격 전략
- **Best 패키지**: 가장 추천, 개당 가격이 합리적
- **Heavy 패키지**: 대량 구매 시 할인 효과
- **Limited 패키지**: 보너스 제공으로 가성비 최고

### 시나리오 1: 마이페이지에서 충전하기
```
1. 마이페이지(MY 탭) 진입
   ↓
2. "큐피드 화살" 카드 확인
   ↓
3. "충전" 버튼 클릭
   ↓
4. 큐피드 샵 페이지로 이동
   ↓
5. 원하는 패키지 선택
   ↓
6. "충전하기" 버튼 클릭
   ↓
7. 로그인 확인 (비로그인 시 로그인 페이지로 이동)
   ↓
8. 결제 프로세스 진행
   ↓
9. 결제 완료 후 화살 충전
   ↓
10. 성공 메시지 표시
```

### 시나리오 2: 화살 부족 시 자동 이동
```
1. 답장 생성 등 화살이 필요한 기능 사용 시도
   ↓
2. 화살 잔액 부족 감지
   ↓
3. 큐피드 샵 페이지로 자동 이동
   ↓
4. 패키지 선택 및 결제
   ↓
5. 충전 후 원래 기능으로 복귀
```

### 시나리오 3: 비로그인 사용자
```
1. 큐피드 샵 페이지 진입
   ↓
2. 패키지 선택 및 "충전하기" 클릭
   ↓
3. 로그인 페이지로 이동
   ↓
4. 로그인 완료
   ↓
5. 큐피드 샵 페이지로 복귀
   ↓
6. 결제 프로세스 진행
```

## 📝 참고사항

- **로그인 필수**: 결제를 위해서는 로그인이 필요합니다
- **결제 방식**: 현재 카카오페이만 지원 (추후 확장 가능)
- **화살 유효기간**: 화살은 유효기간이 없으며 언제든 사용 가능합니다
- **환불 정책**: 구매한 화살은 환불이 불가능합니다
- **결제 안전성**: PortOne 결제 시스템을 통한 안전한 결제 보장
- **통계 수집**: 구매 내역과 사용 통계를 수집하여 서비스 개선에 활용합니다
