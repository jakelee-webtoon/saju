# 궁합 보기 기능 명세서

## 📌 기능 개요

궁합 보기 기능은 사용자의 사주 정보를 기반으로 상대방과의 궁합을 분석하는 기능입니다. MBTI 또는 생년월일 정보를 입력받아 두 사람의 궁합 점수를 계산하고, 구체적인 분석 결과와 조언을 제공합니다.

**비즈니스 가치:**
- 사용자가 궁금해하는 상대방과의 궁합을 명확하게 파악할 수 있도록 도움
- 사주 기반 분석으로 차별화된 서비스 제공
- 궁합 결과 공유를 통한 바이럴 마케팅 가능
- 상대방 정보 저장을 통한 지속적인 앱 사용 유도

---

## 🏠 화면 구성

### 접근 경로
- 홈 화면의 "궁합 보기" 카드 클릭
- 직접 접근: `/match` 경로로 이동

### 상단 헤더
- **뒤로가기 버튼**: 홈 화면으로 복귀
- **제목**: "💞 궁합 보기"
- **설명**: "내 사주 기반으로 상대방과의 궁합을 확인해보세요"

### 진행 표시
- 2단계 진행 표시 바
- 현재 단계에 따라 진행 상태 표시

## 📝 입력 단계

### Step 1: 상대방 정보 입력

#### 저장된 상대방이 있는 경우
**표시 내용:**
- "저장된 상대 정보" 안내
- 상대방 이름 (큰 글씨)
- MBTI 태그 (MBTI가 입력된 경우)
- "사주 입력됨" 태그 (사주 정보가 있는 경우)
- "{이름}님과의 궁합 보기 →" 버튼

**동작:**
- 버튼 클릭 시 저장된 정보로 바로 궁합 계산
- MBTI 정보가 있으면 MBTI 궁합 계산
- 사주 정보만 있으면 생년월일 궁합 계산

#### 저장된 상대방이 없는 경우
**표시 내용:**
- "저장된 상대 정보가 없어요" 안내
- "상대 정보를 먼저 저장하면 궁합을 더 쉽게 확인할 수 있어요" 설명
- "상대방 정보 입력하러 가기 →" 버튼

**상대방 별명 입력:**
- 입력 필드: 텍스트 입력
- 플레이스홀더: "예: 썸남, 직장동료, 친구"
- 최대 길이: 10자
- 글자 수 표시: "{현재 글자 수}/10자"

**다음 버튼:**
- 활성 조건: 별명이 1자 이상 10자 이하일 때
- 비활성 상태: 회색 배경, 클릭 불가

### Step 2: 궁합 방식 선택

#### 입력된 정보 표시
- "{별명}님과의 궁합" 표시
- "수정" 버튼 (Step 1로 돌아가기)

#### 궁합 방식 선택 탭
**두 가지 방식 중 선택:**

1. **상대방 MBTI로 보기**
   - 버튼 텍스트: "상대방 **MBTI**로 보기"
   - 선택 시 보라색 배경, 흰색 텍스트
   - 미선택 시 회색 배경

2. **상대방 생년월일로 보기**
   - 버튼 텍스트: "상대방 **생년월일**로 보기"
   - 선택 시 보라색 배경, 흰색 텍스트
   - 미선택 시 회색 배경

#### MBTI 선택 (MBTI 방식 선택 시)
- **MBTI 피커**: 16가지 MBTI 유형 중 선택
- **선택 안내**: "{별명}님의 MBTI를 선택하세요" 또는 "선택됨: {MBTI}"
- **선택 방식**: MBTI 선택 도구 사용

#### 생년월일 입력 (생년월일 방식 선택 시)
- **입력 안내**: "{별명}님의 생년월일을 입력하세요"
- **입력 필드**:
  - 연도: 드롭다운 선택 (현재 연도부터 80년 전까지)
  - 월: 드롭다운 선택 (1월~12월)
  - 일: 드롭다운 선택 (1일~31일)
- **출생 시간 입력 (선택)**:
  - "출생 시간도 입력할게요 (선택)" 체크박스
  - 체크 시 시간 드롭다운 표시 (0시~23시)
  - 시간 표시: "0시 (자정)", "12시 (정오)", "오전/오후" 구분
  - 안내 문구: "시간을 알면 더 정확한 시주 분석이 가능해요"
- **입력 확인**: 입력된 생년월일 표시
  - 예: "입력: 1995.3.15 14시"
- **안내 문구**: "💡 띠 궁합 + 오행 관계로 분석해드려요"

#### 궁합 보기 버튼
- **버튼 텍스트**: "💕 우리 궁합 확인하기"
- **활성 조건**: 
  - MBTI 방식: 별명 입력 + MBTI 선택 완료
  - 생년월일 방식: 별명 입력 + 생년월일 입력 완료
- **비활성 상태**: 회색 배경, 클릭 불가

#### 돌아가기 버튼
- **버튼 텍스트**: "← 돌아가기"
- **동작**: Step 1로 돌아가기

## 📊 궁합 결과 화면

### 결과 표시 순서
1. 헤더 (상대방 이름, 분석 방식)
2. 궁합 점수 카드
3. 선언문/헤드라인
4. 좋은 점
5. 조심할 점
6. 오늘 추천
7. 상세 궁합 분석
8. 액션 버튼

### MBTI 궁합 결과

#### 헤더
- **제목**: "{별명}님과의 궁합"
- **부제**: "내 사주 기반 × {상대방 MBTI}"

#### 궁합 점수 카드
- **점수 표시**: 큰 숫자로 표시 (0-100점)
- **등급 표시**: 점수에 따른 등급 표시
  - 90점 이상: "최고의 궁합" (이모지 + 색상)
  - 80점 이상: "아주 좋은 궁합" (이모지 + 색상)
  - 70점 이상: "좋은 궁합" (이모지 + 색상)
  - 60점 이상: "무난한 궁합" (이모지 + 색상)
  - 50점 이상: "보통 궁합" (이모지 + 색상)
  - 50점 미만: "노력이 필요한 궁합" (이모지 + 색상)

#### 선언문
- **형식**: 따옴표로 감싼 한 문장
- **내용**: 점수와 등급에 맞는 선언문
- **예시**: "서로를 완벽하게 보완하는 운명적인 조합이에요"

#### 좋은 점
- **제목**: "✨ 좋은 점"
- **표시 방식**: 리스트 형태 (최대 3개)
- **내용**: MBTI 조합에서 나타나는 긍정적 특성
- **예시**:
  - "에너지 방향이 같아요"
  - "대화 스타일이 잘 맞아요"
  - "서로 다른 에너지로 보완해요"

#### 조심할 점
- **제목**: "⚠️ 조심할 점"
- **표시 방식**: 리스트 형태 (최대 2개)
- **내용**: MBTI 조합에서 주의해야 할 부분
- **예시**:
  - "대화 방식이 달라 오해가 생길 수 있어요"
  - "감정 표현 방식이 달라요"

#### 오늘 추천
- **제목**: "💡 오늘 추천"
- **내용**: 오늘 하루를 위한 행동 제안 (1-2문장)

#### 상세 궁합 분석
- **제목**: "🔓 상세 궁합 분석"

**분석 항목:**

1. **왜 잘 맞나면**
   - 제목: "💚 왜 잘 맞나면"
   - 내용: 두 MBTI 유형이 잘 맞는 이유 설명
   - 예: "{내 MBTI}의 외향적 에너지와 {상대방 MBTI}의 활발함이 서로를 완벽하게 보완해줘요"

2. **주의할 포인트**
   - 제목: "⚡ 주의할 포인트"
   - 내용: 갈등이 생길 수 있는 부분과 해결 방법
   - 예: "계획 vs 즉흥 스타일 차이가 있어서, 여행이나 데이트 계획 시 미리 조율이 필요해요"

3. **관계 꿀팁**
   - 제목: "💡 관계 꿀팁"
   - 내용: 점수에 따른 관계 유지 팁
   - 예: "이미 좋은 케미! 서로의 장점을 자주 말해주면 더 깊어져요"

## 🔢 궁합 점수 계산 로직

### MBTI 궁합 점수

#### 기본 점수
- **시작 점수**: 55점

#### 축별 점수 (4개 축)
1. **E/I (에너지 방향)**
   - 같으면: +8점
   - 다르면: +4점

2. **N/S (인식 방식)**
   - 같으면: +10점
   - 다르면: -6점

3. **T/F (결정 방식)**
   - 같으면: +8점
   - 다르면: -4점

4. **J/P (생활 리듬)**
   - 같으면: +6점
   - 다르면: -2점

#### 보너스/패널티
- N 둘 다: +4점
- S 둘 다: +3점
- F 둘 다: +3점
- T 둘 다: +2점
- (J와 P가 다르고, E도 다르면): -3점

#### 최종 점수
- 기본 점수 + 축별 점수 + 보너스/패널티
- 0-100점 범위로 제한

### 생년월일 궁합 점수

#### 기본 점수
- **시작 점수**: 55점

#### 오행 관계 점수
- **상생**: +12점 (서로를 북돋아주는 관계)
- **비화**: +8점 (같은 에너지로 공감)
- **중립**: +4점 (적당한 거리감)
- **상극**: -6점 (부딪힐 수 있음)

#### 띠 관계 점수
- **육합**: +12점 (가장 조화로운 짝)
- **삼합**: +10점 (함께 큰 에너지 형성)
- **같은 띠**: +8점 (동질감)
- **충돌**: -6점 (마찰 가능)

#### 오행 분포 보완
- 서로 부족한 오행을 보완: +4점
- 둘 다 같은 오행 과다: -3점

#### 생일 특성
- 같은 달: +3점
- 날짜 차이 0~3일: +2점
- 둘 다 20일 이후: +1점

#### 최종 점수
- 기본 점수 + 오행 관계 + 띠 관계 + 오행 분포 + 생일 특성
- 0-100점 범위로 제한

## 🔄 사용자 플로우

### 시나리오 1: 저장된 상대방으로 궁합 보기
```
1. 궁합 보기 페이지 진입
   ↓
2. 저장된 상대방 정보 확인 카드 표시
   ↓
3. "{이름}님과의 궁합 보기" 버튼 클릭
   ↓
4. 저장된 정보로 자동 궁합 계산

```

### 시나리오 2: 새 상대방 정보 입력하여 궁합 보기
```
1. 궁합 보기 페이지 진입
   ↓
2. "저장된 상대 정보가 없어요" 안내 확인
   ↓
3. 상대방 별명 입력 (Step 1)
   ↓
```
