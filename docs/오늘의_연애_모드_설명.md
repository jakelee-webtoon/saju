# 오늘의 연애 모드 (Today's Love Mode)

## 📌 개요

"오늘의 연애 모드"는 사용자의 사주 정보를 기반으로 매일 다른 연애 감정 상태를 분석하고 제시하는 핵심 기능입니다. 사용자의 생년월일과 시간 정보를 바탕으로 생성된 **캐릭터(사주 기반 성향)**와 **날짜**를 조합하여, 오늘 하루의 연애 감정 흐름을 80개 이상의 모드 중 하나로 진단합니다.

---

## 🔄 동작 원리

### 1. 입력 데이터
- **사주 정보**: 사용자의 생년월일, 출생 시간 (음력/양력)
- **날짜**: 오늘 날짜 (한국 시간 기준, KST)
- **캐릭터**: 사주에서 추출된 오행(화수목토금) 기반 성향

### 2. 계산 프로세스

#### Step 1: 캐릭터 오행 추출
- 사용자의 사주 정보를 분석하여 오행(화, 수, 목, 토, 금) 중 하나를 결정
- 각 오행은 특정 연애 모드와 높은 연관성을 가짐

#### Step 2: 가중치 적용

**1. 오행별 가중치**
- **화(火)**: 급발진, 직진모드, 강렬모드 등이 나올 확률이 **3배** 높음
- **수(水)**: 쿨다운, 관망모드, 미스터리모드 등이 나올 확률이 **3배** 높음
- **목(木)**: 기대모드, 모험모드, 성장모드 등이 나올 확률이 **3배** 높음
- **토(土)**: 안정모드, 인내모드, 정리모드 등이 나올 확률이 **3배** 높음
- **금(金)**: 현실모드, 선별모드, 확신모드 등이 나올 확률이 **3배** 높음

**2. 요일별 가중치**
- **일요일**: 외로움모드, 힐링모드, 나른모드 (1.5배)
- **월요일**: 현실모드, 집중모드, 신중모드 (1.5배)
- **화요일**: 대화모드, 직진모드 (1.2~1.5배)
- **수요일**: 균형모드, 양보모드 (1.2~1.5배)
- **목요일**: 기대모드, 모험모드, 플러팅모드 (1.2~1.5배)
- **금요일**: 장난모드, 로맨틱모드, 신남모드 (1.5배)
- **토요일**: 설렘모드, 애정표현모드, 자유모드 (1.5배)

**3. 날짜 기반 변동**
- 같은 날짜는 항상 같은 시드 값을 생성
- 시드 기반 의사 난수로 미세한 변동성 추가

#### Step 3: 모드 선택
- 모든 모드의 가중치를 누적하여 확률 분포 생성
- 날짜 + 캐릭터 ID 조합으로 결정론적 시드 생성
- 시드 기반으로 최종 모드 선택

### 3. 일별 고정 메커니즘
- **같은 날짜 + 같은 캐릭터 = 항상 같은 모드**
- 한국 시간(KST) 기준으로 날짜 계산
- 모드 ID로 정렬하여 순서 고정 (결정론적 선택 보장)

## 📊 모드별 상세 정보

각 모드는 다음 정보를 포함합니다:

1. **모드 이름 & 이모지**: 시각적 식별
2. **홈 요약**: 홈 화면에 표시되는 한 줄 요약
3. **메인 문장**: 오늘의 상태를 한 문장으로 표현
4. **이유**: 왜 이런 모드인지 설명
5. **트리거**: 이런 상황에서 흔들릴 수 있는 요소들
6. **한 줄 가이드**: 오늘 하루를 위한 조언

## 🎨 시각적 표현

- **색상 테마**: 각 모드마다 고유한 그라데이션 배경색
  - 예: 쿨다운 (하늘색), 급발진 (빨강-주황), 미스터리모드 (보라-바이올렛)
- **이모지**: 모드를 직관적으로 표현하는 이모지
- **배지**: 모드 이름이 강조된 배지 형태로 표시

## 💡 사용자 경험

### 홈 화면
- 큰 히어로 카드로 오늘의 모드 표시
- 모드 이름, 이모지, 요약 문장 제공
- 클릭 시 상세 페이지로 이동

### 상세 페이지
- 모드의 전체 설명
- "오늘 왜 이런 모드냐면" - 이유 설명
- "오늘 이럴 때 특히 흔들릴 수 있어" - 주의사항
- "오늘의 한 줄 가이드" - 실용적 조언
- "오늘의 연애 결정 가이드" - 질문과 답변 형식의 추가 가이드

### 공유 기능
- 이미지로 공유 가능
- 모드 이름, 이모지, 핵심 메시지 포함
- 브랜딩 정보 자동 포함
