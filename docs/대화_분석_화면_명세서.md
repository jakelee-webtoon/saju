# 상대방과 나의 대화 분석 화면 명세서

## 📌 기능 개요

대화 분석 기능은 사용자가 카카오톡 대화 내용을 입력하면 AI가 상대방의 감정, 호감도, 답장 패턴 등을 분석하여 구체적인 인사이트를 제공하는 핵심 기능입니다. 분석 결과를 바탕으로 사용자가 다음 행동을 결정할 수 있도록 실용적인 조언을 제공합니다.

**비즈니스 가치:**
- 사용자가 궁금해하는 상대방의 마음을 명확하게 파악할 수 있도록 도움
- 구체적인 행동 지침 제공으로 사용자의 결정을 지원
- MBTI 정보를 활용한 더 정확한 분석으로 사용자 만족도 향상
- 분석 결과를 바탕으로 답장 생성 기능으로 자연스러운 연결

## 🏠 화면 구성

### 접근 경로
- 홈 화면의 "상대방과의 나의 대화분석" 카드 클릭
- 하단 네비게이션의 "대화분석" 탭 클릭

### 상단 헤더
- **뒤로가기 버튼**: 이전 화면으로 복귀
- **제목**: "카톡 대화 분석"
- **설명**: "대화 내용으로 상대 마음 읽기"

## 📥 입력 영역

### 분석 대상 정보 카드
**표시 조건**: 현재 상대로 설정된 상대방이 있는 경우

**표시 내용:**
- 분석 대상 표시 (이모지 + "분석 대상" 텍스트)
- 상대방 이름 (큰 글씨, 굵게)
- MBTI 태그 (MBTI가 입력된 경우)
- 관계 단계 태그 (관계 단계가 입력된 경우)
- "현재 상대입니다" 안내 문구
- "상대 변경" 버튼 (상대 관리 페이지로 이동)

### 대화 입력 방법

#### 방법 1: 카톡 스크린샷 업로드
- **최대 업로드 개수**: 3장
- **첫 번째 이미지**: 필수, 가로로 긴 형태
- **두 번째, 세 번째 이미지**: 선택, 정사각형 형태로 가로 배치
- **이미지 처리**: 업로드 즉시 OCR(이미지에서 텍스트 추출) 자동 처리
- **처리 중 표시**: 스피너 애니메이션과 "처리 중..." 메시지
- **이미지 미리보기**: 업로드된 이미지 썸네일 표시
- **이미지 삭제**: 각 이미지에 삭제 버튼 제공

**OCR 처리 특징:**
- 여러 이미지 업로드 시 자동으로 대화 순서 인식
- 중복된 대화 내용 자동 제거
- 발화자 구분 자동 처리 ("나:" 접두사 자동 추가)

#### 방법 2: 텍스트 직접 입력
- **입력 필드**: 여러 줄 텍스트 입력 영역
- **플레이스홀더**: 대화 입력 예시 제공
  ```
  예시:
  나: 오늘 뭐해?
  상대: 집에 있어
  나: 심심하겠다 ㅋㅋ
  상대: 응 ㅋㅋ 너는?
  나: 나도 집에 있는데
  상대: 그럼 만날까?
  ```
- **최소 입력 길이**: 최소 5줄 이상의 대화 필요
- **지우기 버튼**: 입력 내용이 있으면 "지우기" 버튼 표시

### 분석 시작 버튼
- **버튼 텍스트**: "🔮 분석 시작하기"
- **활성 조건**: 대화 내용이 입력되어 있고, 이미지 처리 중이 아닐 때
- **비활성 상태**: 회색 배경, 클릭 불가
- **분석 중 표시**: 
  - 버튼 텍스트가 "분석 중..."으로 변경
  - 스피너 애니메이션 표시
  - 하단에 진행 게이지 바 표시 (애니메이션 효과)

### 프라이버시 안내
- **위치**: 입력 영역 하단
- **내용**: 
  - "🔒 프라이버시 보호"
  - "사용자의 대화 내용은 절대 저장되지 않으며, 분석 용도로만 일시적으로 처리됩니다."

## 📊 분석 결과 영역

### 결과 표시 순서
분석 결과는 다음 순서로 표시됩니다:

1. 이 대화의 핵심 요약
2. 호감도 분석
3. 답장 패턴 상세
4. 상대 마음에서 보이는 신호 3가지
5. 지금 이 타이밍에서 중요한 선택
6. 단기 관계 전망

### ① 이 대화의 핵심 요약
- **디자인**: 인디고-보라 그라데이션 배경, 흰색 텍스트
- **구성**:
  - 섹션 제목: "이 대화의 핵심 요약"
  - 첫 번째 줄: "지금 이 대화는" 또는 "이 대화의 핵심은 이거예요"
  - 두 번째 줄: 호감도 점수에 따른 핵심 메시지 (큰 글씨, 굵게, 따옴표 처리)
- **메시지 예시**:
  - 80점 이상: "'마음은 열려 있는데, 속도는 아직 상대 리듬'이에요"
  - 60점 이상: "'편안함 + 호감은 있지만, 밀당이 필요한 구간'이에요"
  - 40점 이상: "'좋아 보이지만, 안 급해 보이길 바라는 상태'"
  - 20점 이상: "'관심은 있지만, 확신이 서지 않는 단계'예요"
  - 20점 미만: "'거리를 두면서도 완전히 끊지 않는 상태'"

### ② 호감도 분석
- **섹션 제목**: "📊 호감도 분석"

#### 호감도 점수 카드
- **점수 표시**: 큰 숫자로 표시 (0-100점)
- **진행 바**: 점수에 비례한 진행 바 표시
  - 점수에 따라 색상 변경 (초록, 파랑, 노랑, 주황, 빨강)
- **점수 라벨**: 점수 구간에 따른 라벨 표시
  - 80점 이상: "강한 호감"
  - 60점 이상: "긍정적 관심"
  - 40점 이상: "중립/관찰"
  - 20점 이상: "소극적"
  - 20점 미만: "거부/회피"
- **비유 문장**: 점수를 비유로 표현
  - 예: "→ 손은 잡을 수 있지만, 팔짱은 아직 어색한 온도"

#### 점수 산정 근거 카드
- **표시 조건**: 점수 근거 정보가 있는 경우
- **내용**: 점수를 산정한 구체적 근거 설명
  - 예: "78점 → 질문 4회, 긍정 리액션 6회, 답장 평균 12분"

#### 구체적 행동 패턴 분석
- **제목**: "구체적 행동 패턴 분석"
- **표시 방식**: 번호가 매겨진 카드 형태로 표시
- **내용**: 대화에서 관찰된 구체적 행동 패턴 3개
  - 각 패턴은 번호와 함께 카드 형태로 표시
  - 왼쪽에 색상이 있는 테두리로 시각적 구분

### ③ 답장 패턴 상세
- **섹션 제목**: "⏱️ 답장 패턴 상세"
- **표시 조건**: 답장 패턴 정보가 있는 경우

#### 패턴 항목 (최대 4개)

**1. 평균 답장 속도**
- **라벨**: "평균 답장 속도"
- **값**: 예) "빠른 편", "보통", "느린 편"
- **설명**: 답장 속도에 대한 구체적 분석 (MBTI 언급 없음)

**2. 질문 주도권**
- **라벨**: "질문 주도권"
- **값**: 예) "상대가 더 많이 질문", "비슷함", "내가 더 많이 질문"
- **설명**: 대화에서 누가 더 질문을 주도하는지 분석

**3. 감정 밀도**
- **라벨**: "감정 밀도"
- **값**: 예) "높음", "보통", "낮음"
- **설명**: "ㅋㅋ", "ㅎㅎ", "!", 이모티콘 등의 사용 빈도 분석

**4. 답장 패턴 해석** (MBTI 정보가 있는 경우)
- **라벨**: "답장 패턴 해석"
- **값**: 상대방의 MBTI 유형
- **설명**: MBTI 기반 답장 패턴 해석 (구체적이고 친근한 톤)

**표시 방식:**
- 각 패턴은 카드 형태로 표시
- 왼쪽에 아이콘 표시 (⚡, 💬, 💫, 🎯)
- 오른쪽에 값이 배지 형태로 표시
- 하단에 설명 텍스트 표시

### ④ 상대 마음에서 보이는 신호 3가지
- **섹션 제목**: "🔍 상대 마음에서 보이는 신호 3가지"

**표시 내용:**
- **신호 1**: 호감도 근거 중 첫 번째 (파란색 배경)
- **신호 2**: 호감도 근거 중 두 번째 또는 감정 흐름 요약 (보라색 배경)
- **신호 3**: 호감도 근거 중 세 번째 또는 감정 흐름 첫 문장 (초록색 배경)

**표시 방식:**
- 각 신호는 번호가 매겨진 원형 배지와 함께 카드 형태로 표시
- 왼쪽에 색상이 있는 테두리로 시각적 구분
- 각 신호는 다른 색상 그라데이션 배경 사용

### ⑤ 지금 이 타이밍에서 중요한 선택
- **섹션 제목**: "⚡ 지금 이 타이밍에서 중요한 선택"

#### 지금은 이게 좋아요
- **제목**: "지금은 이게 좋아요"
- **내용**: 행동 지침 2개 (체크마크와 함께 리스트 형태)
  - 예: "오늘 하루가 어떤지 등 가벼운 질문을 하는 게 좋아요"
  - 예: "상대방의 대화로부터 기분 좋은 감정을 느낄 수 있다고 말하는 게 좋아요"

#### 행동 요약
- **내용**: 현재 상황에 대한 전략적 행동 제안 (2-3문장)

#### 행동 선택 버튼
- **안내 문구**: "각 선택지를 눌러보면 예상 결과를 확인할 수 있어요"
- **선택지 3개**:
  1. **편하게 이어가기**
     - 부제: "→ 안정 유지"
     - 클릭 시 결과: "지금 대화만 보면, 상대는 '불편함 없이 이어가도 되겠다'는 신호를 보내고 있어요. 현재 리듬을 유지하는 게 안전해 보여요"
  
  2. **조금 더 다가가기**
     - 부제: "→ 리스크 있지만 진전 가능"
     - 클릭 시 결과: "적어도 이 대화에서는 당신을 귀찮아하거나 밀어내는 느낌은 없어요. 하지만 속도를 재촉하면 부담을 줄 수 있어요"
  
  3. **기다리기**
     - 부제: "→ 상대 주도권 존중"
     - 클릭 시 결과: "상대가 먼저 말을 꺼내는 걸 기다리면, 주도권을 존중하는 느낌을 줄 수 있어요. 지금 타이밍에서는 이게 더 자연스러울 수 있어요"

**동작:**
- 선택지 클릭 시 해당 선택지가 강조 표시됨
- 선택 시 하단에 예상 결과 카드 표시

### ⑥ 단기 관계 전망
- **섹션 제목**: "단기 관계 전망"
- **내용**: 1~3일 기준 감정 흐름 예측
- **안내 문구**: "💡 1~3일 기준 감정 흐름 예측은 참고용이며, 실제 관계는 더 복잡할 수 있어요"

  - 중앙에 모달 창 표시
  - "🔮" 이모지 애니메이션

  - "상대방의 감정과 호감도를 분석하고 있어요" 설명
  - 스피너 애니메이션

- **표시 위치**: 입력 영역 내부

- **오류 메시지 예시**:
  - "대화 내용을 입력해주세요"
  - "이미지 파일만 업로드할 수 있어요"
  - "이미지 크기는 10MB 이하여야 해요"

### 다시 분석하기
- **위치**: 분석 결과 최상단
- **버튼 텍스트**: "← 다른 대화 분석하기"
- **동작**: 클릭 시 모든 입력 내용과 분석 결과 초기화, 입력 화면으로 복귀

## 🎯 분석 로직

### 입력 검증
- **최소 대화 길이**: 최소 5줄 이상
- **최대 대화 길이**: 1500자 (초과 시 자동 잘림)
- **이미지 제한**: 
  - 파일 형식: 이미지 파일만 허용
  - 파일 크기: 최대 10MB

### 분석 항목
1. **호감도 점수**: 0-100점으로 계산
2. **답장 패턴**: 평균 답장 속도, 질문 주도권, 감정 밀도
3. **행동 패턴**: 질문 빈도, 리액션 패턴, 주제 확장 여부
4. **위험 신호**: 관심 저하, 거리두기 등의 패턴 감지

### MBTI 활용
- **활용 조건**: 현재 상대로 설정된 상대방의 MBTI 정보가 있는 경우
- **활용 방식**: 
  - MBTI를 확률 조정 요소로 사용
  - 일반론이 아닌 이번 대화에서 보인 구체적 패턴 해석
  - 답장 패턴 해석에 MBTI 기반 설명 추가

## 💡 주요 특징

### 1. 다양한 입력 방식 지원
- 이미지 업로드: 카톡 스크린샷을 업로드하면 자동으로 텍스트 추출
- 텍스트 직접 입력: 대화 내용을 직접 입력 가능
- 여러 이미지 지원: 최대 3장까지 업로드하여 긴 대화 분석 가능
