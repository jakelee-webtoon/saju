# 사주큐피드 앱 전체 설명

## 📌 앱 소개

**사주큐피드**는 사주(四柱)를 기반으로 한 연애 분석 및 조언 앱입니다. 사용자의 생년월일과 출생 시간을 바탕으로 개인 맞춤형 연애 캐릭터를 생성하고, 매일 바뀌는 연애 감정 상태를 분석하여 실용적인 연애 조언을 제공합니다.

---

## 🏠 홈 화면 구성

### 상단 헤더
- **사용자 이름 + 오늘의 모드 이모지** (예: "홍길동님 🧊")
- **오늘 날짜** (요일 포함, 예: "12월 17일 월요일")
- **정보 수정 버튼** (우측 상단) - 생년월일 정보 수정

### 메인 카드 영역

#### ① 오늘의 연애 카드 (가장 큰 카드)
- **위치**: 헤더 바로 아래
- **디자인**: 모드별 고유 그라데이션 배경색, 둥근 모서리
- **표시 내용**:
  - 날짜 배지
  - "💗 오늘의 연애" 섹션 타이틀
  - 모드 이모지 + 모드 이름 (예: "🧊 쿨다운")
  - 핵심 한 줄 메시지 (오늘의 연애 상태 요약)
  - 한 줄 가이드 (오늘 하루를 위한 조언)
  - "오늘, 이대로 가도 될까? →" 문구
- **기능**: 클릭 시 → 오늘의 연애 상세 페이지로 이동

#### ② 현재 상대 카드
- **위치**: 오늘의 연애 카드 아래
- **디자인**: 직사각형 흰색 카드, 왼쪽에 프로필 아이콘
- **표시 내용** (상대가 설정된 경우):
  - "💞 현재 상대" 타이틀
  - "설정됨" 배지
  - 상대 이름 (큰 글씨)
  - 관계 단계 태그 (예: "연인", "친구")
  - MBTI 태그 (예: "INFP")
- **표시 내용** (상대가 없는 경우):
  - "상대 관리" 타이틀
  - "상대 정보를 저장하고 분석에 반영해요" 안내
- **기능**: 클릭 시 → 상대 관리 페이지로 이동

#### ③ 상대방과의 나의 대화분석 카드
- **위치**: 현재 상대 카드 아래
- **디자인**: 파란색-인디고 그라데이션 배경, 무지개 테두리 애니메이션
- **표시 내용**:
  - "💬 상대방과의 나의 대화분석" 타이틀
  - "카톡 대화로 상대 마음 읽기" 설명
- **기능**: 클릭 시 → 대화분석 탭으로 이동

#### ④ 답장 자동 생성기 카드
- **위치**: 대화분석 카드 아래
- **디자인**: 보라색-핑크 그라데이션 배경
- **표시 내용**:
  - "✨ 답장 자동 생성기" 타이틀
  - "AI가 만들어주는 완벽한 답장" 설명
- **기능**: 클릭 시 → 답장 탭으로 이동

#### ⑤ 궁합 보기 카드
- **위치**: 답장 자동 생성기 카드 아래
- **디자인**: 보라색-핑크 그라데이션 배경
- **표시 내용**:
  - "💞 궁합 보기" 타이틀
  - "상대방과의 궁합을 확인해보세요" 설명
- **기능**: 클릭 시 → 궁합 페이지로 이동

## 🧭 하단 네비게이션 (4개 탭)

화면 최하단에 고정되어 있는 네비게이션 바입니다. 항상 화면에 표시되며, 탭 간 빠른 이동을 가능하게 합니다.

### 1. 홈 탭 (🏠)
- **기능**: 홈 화면으로 이동
- **활성 표시**: 인디고색 배경 + 진한 텍스트

### 2. 대화분석 탭 (💬)
- **기능**: 대화 분석 페이지로 이동
- **특징**: 새 알림이 있을 경우 아이콘 우측 상단에 빨간 점 표시

### 3. 답장 탭 (✨)
- **기능**: AI 답장 생성기 페이지로 이동

### 4. MY 탭 (👤)
- **기능**: 마이페이지로 이동

## 📱 주요 기능

### 1. 오늘의 연애 모드
- **기능**: 사용자의 사주 기반 캐릭터와 오늘 날짜를 조합하여 매일 다른 연애 감정 상태를 진단
- **모드 종류**: 80개 이상의 모드 (예: 쿨다운, 급발진, 설렘모드, 관망모드 등)
- **표시 정보**:
  - 오늘의 연애 상태 (모드 이름 + 이모지)
  - 핵심 메시지 (왜 이런 모드인지)
  - 주의사항 (오늘 이럴 때 흔들릴 수 있는 요소)
  - 한 줄 가이드 (실용적 조언)
  - 연애 결정 가이드 (질문과 답변 형식)
- **특징**: 매일 자정(KST)에 자동으로 변경

### 2. 대화 분석
- **기능**: 카카오톡 대화를 분석하여 상대방의 감정과 호감도를 파악
- **입력 방법**:
  - 대화 이미지 업로드 (최대 3장) - OCR로 자동 추출
  - 텍스트 직접 입력
- **분석 결과**:
  - 이 대화의 핵심 요약 (한 줄로 현재 관계 상태 정의)
  - 호감도 분석 (0-100점, 근거 포함)
  - 답장 패턴 상세 (평균 답장 속도, 질문 주도권, 감정 밀도, MBTI 기반 해석)
  - 상대 마음에서 보이는 신호 3가지
  - 지금 이 타이밍에서 중요한 선택 (행동 지침 + 선택지)
  - 단기 관계 전망 (1-3일 기준 감정 흐름 예측)
- **특징**: 상대방의 MBTI 정보가 있으면 더 정확한 분석 제공

### 3. AI 답장 생성기
- **기능**: 상대방의 메시지를 입력하면 AI가 상황에 맞는 답장을 생성
- **스타일 선택**:
  - 프리셋: 밀당, 설레게, 진심, 쿨하게, 애교, 직진 등
  - 개별 톤: 친근, 쿨, 애교, 직진, 센스, 섹시, 로맨틱, 솔직, 논리적, 츤데레, 팩폭
- **생성 방식**:
  - 무료: 일일 제한 횟수 내에서 무료 사용 가능
  - 유료: 큐피드 화살을 소모하여 추가 답장 생성
- **결과**: 여러 개의 답안 제공, 각 답안의 톤과 의도 설명

### 4. 궁합 보기
- **기능**: 상대방과의 궁합을 사주 또는 MBTI로 분석
- **입력 방법**:
  - MBTI로 궁합 보기: 상대방의 MBTI 입력
  - 생년월일로 궁합 보기: 상대방의 생년월일 입력
- **결과**: 궁합 점수, 궁합 해석, 관계 조언

### 5. 상대 관리
- **기능**: 현재 분석 대상인 상대방의 정보를 저장하고 관리
- **저장 정보**:
  - 이름
  - 관계 단계 (예: 친구, 연인, 짝사랑 등)
  - MBTI
  - 생년월일 (선택사항)
- **특징**: 여러 상대를 저장하고 전환 가능

### 6. 마이페이지 (MY 탭)
- **기능**: 사용자 정보 및 앱 설정 관리
- **표시 내용**:
  - 큐피드 화살 보유량 (최상단 강조)
  - 화살 충전하기 버튼
  - 나의 연애 캐릭터 정보
  - 나의 기본 연애 성향
  - 반복 패턴 인사이트
  - 심화 인사이트 (화살 사용)
  - 계정 설정
  - 로그아웃

## 🎯 사용자 플로우

### 첫 방문 사용자
```
1. 앱 진입
   ↓
2. 온보딩 화면 (앱 소개)
   ↓
3. 생년월일 입력 화면
   ↓
4. 캐릭터 리빌 화면 (사주 기반 캐릭터 생성)
   ↓
5. 홈 화면 (오늘의 연애 모드 표시)
```

### 기존 사용자
```
1. 앱 진입 (로그인)
   ↓
2. 홈 화면 (즉시 표시)
   - 오늘의 연애 모드 확인
   - 각 기능 카드로 이동 가능
```

### 기능 사용 예시

#### 대화 분석하기
```
1. 홈 화면에서 "상대방과의 나의 대화분석" 카드 클릭
   또는 하단 네비에서 "대화분석" 탭 클릭
   ↓
2. 대화 이미지 업로드 또는 텍스트 입력
   ↓
3. "분석 시작하기" 버튼 클릭
   ↓
4. 분석 결과 확인
   - 호감도 점수
   - 답장 패턴 분석
   - 행동 조언
   ↓
5. "이 분석으로 답장 만들기" 클릭 (선택)
   → 답장 탭으로 이동하여 답장 생성
```

#### 답장 생성하기
```
1. 홈 화면에서 "답장 자동 생성기" 카드 클릭
   또는 하단 네비에서 "답장" 탭 클릭
   ↓
2. 상대방의 메시지 입력
   ↓
3. 스타일 선택 (밀당, 설레게, 진심 등)
   ↓
4. "답장 생성하기" 버튼 클릭
   ↓
5. 생성된 답장 확인 및 선택
```

#### 오늘의 연애 확인하기
```
1. 홈 화면의 "오늘의 연애" 카드 클릭
   ↓
2. 오늘의 연애 상세 페이지 확인
   - 왜 이런 모드인지 이유
   - 주의사항
   - 한 줄 가이드
   - 연애 결정 가이드
   ↓
3. 이미지로 공유하기 (선택)
```

## 💡 주요 특징

### 1. 개인 맞춤형 분석
- 사용자의 사주 정보를 기반으로 고유한 캐릭터 생성
- 캐릭터와 날짜를 조합하여 매일 다른 연애 모드 제공
- 상대방의 MBTI 정보를 활용한 더 정확한 분석

### 2. 실용적인 조언
- 추상적인 설명이 아닌 구체적인 행동 지침 제공
- 대화 패턴 기반 근거 제시
- 바로 사용할 수 있는 답장 제안

### 3. 매일 새로운 콘텐츠
- 오늘의 연애 모드는 매일 자정에 자동 변경
- 매일 앱을 열어볼 이유 제공

### 4. 직관적인 사용성
- 하단 네비게이션으로 주요 기능에 빠르게 접근
- 카드 형태의 명확한 UI
- 부드러운 화면 전환

### 5. 프라이버시 보호
- 대화 내용은 분석 용도로만 일시적으로 처리
- 사용자의 대화 내용은 저장되지 않음

## 🎨 디자인 특징

  - 오늘의 연애: 모드별 다양한 색상

  - 답장 생성기: 보라색-핑크

### 레이아웃
- 모바일 최적화 (세로 스크롤)
- 카드 기반 UI
- 명확한 계층 구조

### 애니메이션
- 카드 호버 효과
- 부드러운 화면 전환
- 무지개 테두리 애니메이션 (대화분석 카드)

## 📝 참고사항

- **로그인 필수**: 모든 기능은 로그인 후 사용 가능 (카카오/네이버 로그인)
- **화살 시스템**: 답장 생성 등 일부 기능은 큐피드 화살을 소모합니다
- **무료 사용**: 일일 무료 사용 횟수가 제공됩니다
- **상대 정보**: 상대방의 MBTI나 생년월일 정보를 입력하면 더 정확한 분석이 가능합니다
- **일일 모드**: 오늘의 연애 모드는 매일 자정(KST)에 자동으로 변경됩니다
